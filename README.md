# Куда сейчас

Карта Таллина с живыми отметками загруженности приёмных отделений (EMO) — помогает быстро решить, куда ехать при травме или острой боли.

## Стек

Next.js (App Router) + TypeScript + Tailwind CSS, Leaflet/OpenStreetMap, Supabase (Postgres + Realtime + Storage).

## Локальный запуск

1. Создай проект на [supabase.com](https://supabase.com) (бесплатный tier достаточно для MVP).
2. В SQL Editor выполни миграции по порядку:
   - `supabase/migrations/0001_init_schema.sql`
   - `supabase/migrations/0002_seed_locations.sql`
   - `supabase/migrations/0003_enable_realtime.sql`
   - `supabase/migrations/0004_location_notes.sql`
3. В Project Settings → API возьми `Project URL` и `anon public` key.
4. Скопируй `.env.local.example` в `.env.local` и подставь значения:
   ```
   NEXT_PUBLIC_SUPABASE_URL=...
   NEXT_PUBLIC_SUPABASE_ANON_KEY=...
   ```
5. Установи зависимости и запусти dev-сервер:
   ```
   npm install
   npm run dev
   ```
6. Открой http://localhost:3000 — карта Таллина с 4 EMO (приёмными отделениями) + боковой список.

## Как это работает

- **Статус точки** — взвешенная медиана отметок за последние 30 минут (свежие отметки весят больше, экспоненциальное затухание с полураспадом 10 минут). См. `lib/aggregateStatus.ts`.
- **Устаревание** — если свежайшая отметка старше 75 минут, статус переходит в "устарело" (серый, полупрозрачный маркер).
- **Маркеры** — капсула с коротким статусом ("мало"/"есть"/"много") или числом человек, если оно известно; на зуме ниже 13 упрощаются до цветной точки, чтобы не превращаться в кашу текста.
- **Сайдбар** — список всех точек, сортировка по статусу (свободные первыми) или по расстоянию (запрашивает геолокацию по клику). Клик по строке центрирует карту и открывает попап; клик по маркеру подсвечивает строку.
- **Отметка загруженности** — общая логика (гео-проверка, rate-limit, insert) вынесена в `lib/useReportSubmit.ts`, используется и попапом на карте, и компактными кнопками в сайдбаре.
- **Заметки и фото** — при отметке можно оставить короткий текстовый комментарий (до 300 символов) и/или одно фото (Supabase Storage, публичный bucket `location-photos`, лимит 5MB, только изображения). Последние 3-5 заметок и до 3 фото показываются в попапе.
- **Геопроверка** — перед отправкой отметки браузер сверяет геолокацию с координатами точки (допуск 200м). Это фильтр от случайных отметок "не глядя", не защита от намеренного спуфинга.
- **Rate limit** — не чаще одной отметки на точку раз в 15 минут с одного `device_id` (анонимный id в localStorage). Тоже клиентский, честный фильтр — не security-граница; при реальном спаме следующий шаг — Postgres-функция + RLS-проверка по времени на insert. Действует и на заметки/фото — отдельной защиты для них нет.
- **Realtime** — подписка на `postgres_changes` (INSERT) для `queue_reports` и `location_notes`, карта и сайдбар обновляются у всех открытых вкладок без перезагрузки.

## Известные упрощения MVP

- i18n подготовлен структурно (`lib/i18n/`), но подключён только русский.
- Нет аккаунтов, лайков/рейтинга заметок, интеграций с реальными табло, push-уведомлений, мультигорода в UI (поле `city` в схеме уже есть).
- Модерация заметок не реализована — в схеме есть поле `hidden`, но UI для скрытия/жалоб появится следующим этапом.
